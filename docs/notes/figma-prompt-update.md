Below is a production-ready prompt you can give directly to a Figma AI/designer. It tells the designer to **modify the existing design only**, not redesign it, while incorporating the complete CRYPLOUNGE information architecture.

---

# CRYPLOUNGE UI Update Prompt (Keep Existing Design)

## Objective

You are working on the existing Figma design for **CRYPLOUNGE**.

**DO NOT redesign the UI.**

The current design has already been approved.

Your job is to **update the existing design** to support the CRYPLOUNGE product requirements while preserving the visual identity.

---

# Critical Rules

**DO NOT**

* Change the visual style
* Change typography
* Change spacing
* Change color palette
* Change card styles
* Change buttons
* Change grid
* Change responsiveness
* Change image ratios
* Change page width
* Change component styling
* Introduce a different design language

The UI should still look like exactly the same website.

Think of this as an **information architecture update**, not a redesign.

---

# Design Philosophy

CRYPLOUNGE is a premium crypto publication focused on:

* Cryptocurrency
* Blockchain
* Web3
* DeFi
* Centralized Exchanges (CEX)
* Decentralized Exchanges (DEX)
* Infrastructure
* Security
* Regulation
* Institutional Adoption
* Crypto Investment
* Industry Research

It does **NOT** cover:

* General technology
* Politics
* Consumer electronics
* General AI
* Traditional finance (unless crypto related)
