# CRYPLOUNGE – Complete UI Audit & Expansion (No Redesign)

You are working on the **existing approved Figma design** for **CRYPLOUNGE**.

Your task is **NOT** to redesign the website.

Your task is to **audit, complete, and expand** the existing design into a **100% production-ready UI** while preserving the current visual design.

## Critical Instructions

* Do NOT redesign the UI.
* Do NOT change typography.
* Do NOT change spacing.
* Do NOT change colors.
* Do NOT change layout style.
* Do NOT change the visual language.
* Do NOT replace components unnecessarily.

Only **extend and complete** the existing design.

---

# Audit the Entire File

Go through **every page** in the Figma file one by one.

Do not assume any page is complete.

For every page ask:

* Is every section complete?
* Is every interaction designed?
* Is every user flow finished?
* Are there blank areas?
* Are there placeholder components?
* Are there missing screens?
* Are there missing states?
* Are there missing responsive layouts?

If anything is missing, design it.
